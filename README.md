## Features

- **Interactive 3D Models** — Sketchfab embeds for each character, rotatable and zoomable
- **Animated Hero** — Parallax background with staggered entrance animations
- **Scroll Reveal** — Entries animate in with staggered child elements as you scroll
- **Navigation Rail** — Fixed side dots with glow effects and pulse animations
- **Loading States** — Spinner overlays with lazy loading for performance
- **Local Caching** — Previously loaded models cache in localStorage for instant reloads
- **Responsive Design** — Adapts to mobile and desktop viewports

## Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript
- [Three.js](https://threejs.org/) (legacy, removed)
- [Sketchfab](https://sketchfab.com/) 3D embeds
- Google Fonts (Space Grotesk, Inter)

## Getting Started

```bash
git clone https://github.com/charlesevangeliojr/over-powered-anime.git
cd over-powered-anime
open index.html
```

No build tools required — just open `index.html` in a browser.
